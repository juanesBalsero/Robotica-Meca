# Documentación de Ingeniería — Robot 2 (`miau`)

Este directorio centraliza los entregables de ingeniería mecánica, electrónica, matemática y operativa del manipulador de 3 GDL (**Robot 2**).

| Subdirectorio | Contenido Exigido por la Rúbrica | Estado |
| :--- | :--- | :--- |
| [`diagramas/`](diagramas/) | Arquitectura del sistema (ROS 2 + ESP-NOW), secuencia de proceso pick-and-place y diagramas de flujo. | Pendiente de carga |
| [`planos_mecanicos/`](planos_mecanicos/) | Planos de eslabones, ejes, poleas y video explosionado (`explosionado_robot2.mp4`). | Cargado |
| [`planos_electricos/`](planos_electricos/) | Esquemático de potencia, drivers, encoders y las 3 placas ESP32 (`Plano_eléctrico_corregido.pdf`). | Cargado |
| [`memorias_calculo/`](memorias_calculo/) | Cinemática directa/inversa (DH), Jacobiano, análisis dinámico de torques y selección de actuadores. | Pendiente de carga |
| [`datasheets/`](datasheets/) | Hojas de especificaciones de motorreductores, encoders, puentes H, servomotor de pinza y ESP32. | Pendiente de carga |
| [`instructivo_usuario/`](instructivo_usuario/) | Manual de operación, secuencia de encendido, seguridad, solución de fallas y cartilla rápida. | Pendiente de carga |
| [`pruebas_simulacion/`](pruebas_simulacion/) | Árbol TF (`frames_*.pdf`, `frames_*.gv`) y registros CSV de validación (`trajectory_*.csv`). | Cargado |
