# Proyecto de Robótica y Mecatrónica

Este repositorio contiene la documentación técnica, diseños y memorias de cálculo correspondientes al desarrollo del proyecto. A continuación se describe la estructura y el contenido de cada una de las secciones principales:

---

## 📁 Estructura del Repositorio

```text
.
├── Hoja de especificaciones de dispositivos/
├── Instructivo para usuarios/
├── Memoria de Calculo/
│   └── scara_cajas/
├── Planos electricos/
└── Planos mecanicos/
```

---

## 🛠️ Descripción de Contenidos

### 📄 1. Hoja de especificaciones de dispositivos
Contiene los *datasheets*, fichas técnicas y especificaciones de los componentes electrónicos, sensores, actuadores y controladores integrados en el sistema.

### 📖 2. Instructivo para usuarios
Manual de usuario y guías de operación que detallan el uso correcto del equipo, recomendaciones de seguridad, puesta en marcha y mantenimiento preventivo.

### 🧮 3. Memoria de Cálculo (`scara_cajas`)
Documentación matemática, cinemática, dinámica y de dimensionamiento estructural o neumático/eléctrico relativo al módulo o manipulador SCARA para el manejo de cajas.

### ⚡ 4. Planos Eléctricos
Diagramas esquemáticos de las conexiones eléctricas, esquemas de potencia y control, cableado de I/O y distribución de energía del sistema.

### 📐 5. Planos Mecánicos
Modelos 2D y 3D, ensambles, despieces y cotas de las piezas mecánicas y estructura del proyecto para su fabricación o mecanizado.

---
