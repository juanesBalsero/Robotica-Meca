Contiene información respecto al Robot4
Este es el encargado de recoger las tapas de una mesa auxiliar y ubicarlas encima de cada caja que se encuentra en la linea principal.
Este es un Robot de arquitectura tipo SCARA RRP
Cuenta con unas velocidades de Junturas para los Ejes de Rotacion de 2 Radianes por Segundo; y para el eje Prismatico de 15 Centimetros por Segundo
en este apartado se va a poder encontrar toda la documentacion referente a el diseno y creacion de este manipulador de 3 Grados de Libertad (DOF)
asi como sus planos, ya sea de tipo electrico como tipo mecanico, para el cual se utilizo un programa de CAD llamado Solid Works.
